## O que o texto diz

## Reconstrução / lacunas

Ainda não iniciada. Quando processada, esta ficha vai registrar as duas listas **lado a lado**, sem tentar resolver automaticamente as diferenças entre elas — apenas documentá-las:

- Mateus desce de Abraão até Jesus; Lucas sobe de Jesus até Adão.
- Mateus lista José como filho de Jacó; Lucas lista José como filho de Eli — divergência clássica discutida por estudiosos (hipóteses comuns: uma linhagem seria de José e outra de Maria; ou uma seria linhagem legal/de sucessão e outra biológica). Essas hipóteses, quando incluídas, entram claramente identificadas como leitura acadêmica, não como fato bíblico direto.

## Observações

Ponto do projeto onde mais importa não inventar resolução — a ficha deve deixar as duas genealogias completas e as diferenças visíveis.
